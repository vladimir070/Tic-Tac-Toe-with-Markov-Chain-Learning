# Tic-Tac-Toe with Markov Chain Learning

## Description

This project implements the classic Tic-Tac-Toe game with an AI opponent that learns using a Markov Chain. The AI adapts its strategy based on gameplay, becoming a more challenging opponent over time. The project features a graphical user interface built with Tkinter and visualizes the Markov Chain as a heatmap, showing the probabilities of different moves.

## Features

-   Play against an AI opponent that learns from gameplay.
-   AI opponent uses a Markov Chain to adapt its strategy.
-   Graphical user interface built with Tkinter.
-   Visualization of the Markov Chain as a heatmap.
-   Option to train the AI by simulating games.
-   Save and load the AI's learned strategy.
