## Крестики-Нолики с Обучением на Цепях Маркова

## Описание

Этот проект реализует классическую игру Крестики-Нолики с ИИ противником, 
который обучается с использованием цепей Маркова. ИИ адаптирует свою стратегию
на основе игрового процесса, становясь со временем более сложным противником.
Проект включает в себя графический интерфейс, построенный с помощью Tkinter,
и визуализирует цепь Маркова в виде тепловой карты, показывающей вероятности
различных ходов.

##Функциональность

Игра против ИИ противника, который обучается в процессе игры.
ИИ противник использует цепь Маркова для адаптации своей стратегии.
Графический интерфейс, построенный с помощью Tkinter.
Визуализация цепи Маркова в виде тепловой карты.
Возможность обучения ИИ путем симуляции игр.
Сохранение и загрузка выученной стратегии ИИ.
